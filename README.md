# Вязание — готовая сборка

Готовая сборка программы «Вязание»: расчёт выкроек для вязальной машины. Исходники закрыты.

| Файл | Что это |
|---|---|
| `index.html` | вся программа в одном файле, открывается в Edge с диска |
| `version.json` | номер и дата версии: по ним программа узнаёт о новой |
| `vyazanie.ico` | значок |

Обновление — кнопкой «Обновить приложение» на главном экране программы.
